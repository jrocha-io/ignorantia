# APA citation style (7th edition, 2020)

Used in psychology, education, and most social sciences. Author-date in-text, alphabetical reference list. The 7th edition introduced significant changes from the 6th — always use 7th unless explicitly told otherwise.

## In-text — author-date

- Parenthetical: `(Smith, 2023)`, `(Smith & Jones, 2023)`, `(Smith et al., 2023)` for 3+ authors.
- Narrative: `Smith (2023) found that...`, `Smith and Jones (2023) showed...`
- Direct quote: include page — `(Smith, 2023, p. 45)` or `(Smith, 2023, pp. 45–47)`.
- Multiple sources in one parenthesis: alphabetical, semicolon-separated — `(Costa, 2022; Smith, 2023)`.
- Same author multiple years: `(Smith, 2020, 2023)`.
- Same author and year: disambiguate with letters — `(Smith, 2023a)`, `(Smith, 2023b)`.

## Reference list — formats by source type

Reference list is **alphabetical by first author's surname**, with a hanging indent.

### Journal article

```
Author, A. B., Author, C. D., & Author, E. F. (Year). Article title in 
    sentence case: Subtitle in sentence case. Journal Name in Title Case 
    and Italics, Volume(Issue), Pages. https://doi.org/10.xxxx/yyyy
```

Example:
```
Vygotsky, L. S., & Luria, A. R. (2023). Mediated learning in digital 
    environments: A reanalysis. Journal of Educational Psychology, 115(4), 
    721–739. https://doi.org/10.1037/edu0000789
```

### Authors

- Up to 20 authors: list all, with `&` before the last.
- 21+: list first 19, then `...`, then last author.
- Format: `Surname, F. M.`

### Book

```
Author, A. B. (Year). Book title in sentence case and italics 
    (Edition). Publisher.
```

### Book chapter

```
Author, A. B. (Year). Chapter title in sentence case. In C. D. Editor & 
    E. F. Editor (Eds.), Book title in italics (Edition, pp. X–Y). 
    Publisher.
```

### Edited book

```
Editor, A. B. (Ed.). (Year). Book title in italics. Publisher.
```

### Online article / web page

```
Author, A. B. (Year, Month Day). Title of work. Site Name. https://url
```

### Preprint

```
Author, A. B. (Year). Title of preprint. Repository Name. 
    https://doi.org/10.xxxx/yyyy
```

### Conference paper (published in proceedings)

```
Author, A. B. (Year). Paper title. In C. Editor (Ed.), Proceedings of the 
    Conference Name (pp. X–Y). Publisher. https://doi.org/...
```

### Conference paper (unpublished presentation)

```
Author, A. B. (Year, Month Day–Day). Paper title [Conference 
    presentation]. Conference Name, City, Country. https://url
```

### Thesis / dissertation

```
Author, A. B. (Year). Title of dissertation [Doctoral dissertation, 
    University Name]. Repository Name. https://url
```

## DOI / URL formatting

- Always include DOI when available, as `https://doi.org/10.xxxx/yyyy`.
- No "Retrieved from" prefix unless content is liable to change without archive.
- No period at end of DOI/URL.

## Title case rules

- **Article and chapter titles:** sentence case (capitalize only first word, first word after colon, and proper nouns).
- **Journal names:** title case, italicized.
- **Book titles:** sentence case, italicized.

## Tables and figures

APA 7 has detailed table/figure formatting:
- Numbered, with title above (italics), notes below.
- See *Publication Manual of the American Psychological Association*, 7th ed., chapter 7.

## CSL / managers

- Zotero / Mendeley: select "American Psychological Association 7th edition".
- BibTeX with `apacite` or `biblatex-apa` package.
- Official CSL: https://www.zotero.org/styles/apa.
